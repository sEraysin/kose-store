# Şema değişiklikleri

Numaralı SQL dosyaları sırayla uygulanır. İlk dosya ürün tablosunu, personel yetkisini, RLS kurallarını ve görsel depolama alanını oluşturur. İkinci dosya anonim kişilerin personel sorgulama fonksiyonunu çağırmasını engeller. Yeni şema değişiklikleri eski dosyalar düzenlenmeden yeni migration olarak eklenir.
