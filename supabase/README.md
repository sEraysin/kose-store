# Supabase

`config.toml` yerel Supabase CLI ayarlarını tutar. `migrations/` veritabanı şemasını ve erişim kurallarını sürümler. `seed.sql`, `npm run seed:build` ile 40 örnek üründen yeniden üretilir. Uzak projeye uygulama ve mağaza yetkilisi tanımlama adımları için [`docs/dynamic-catalog.md`](../docs/dynamic-catalog.md) dosyasına bak.
